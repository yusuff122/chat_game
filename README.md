# Renk Avi (Flutter)

Cocuklar icin hazirlanan renk eslestirmeli balon patlatma oyunu.

## Oyun Ozeti
- 60 saniyelik hizli tur
- Hedef renkteki balonlara dokunma
- Combo ve seviye sistemi
- Cocuk dostu, reklamsiz ve takipsiz tasarim

## Izin Merkezi
Projede iOS/Android tarafinda yaygin izinler tanimlandi ve uygulama icinde `Izin Merkezi` ekrani ile tek yerden izin isteme akisi olusturuldu.

## Calistirma
```bash
flutter pub get
flutter run
```

## Yayin Notlari
- Android paket adi: `com.yusuf.renkavi`
- iOS Display Name: `Renk Avi`
- iOS/Android izin aciklama metinleri eklendi

Canli yayina cikmadan once gercek marka adi, ikonlar, ekran goruntuleri ve imzalama ayarlari tamamlanmalidir.
